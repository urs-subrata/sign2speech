About Sign2Speech

Sign2Speech is a free, offline Android application designed to translate Indian Sign Language gestures into audible speech. It is built for accessible, accurate, and easy communication on mobile devices.

  • Geometry-Based Architecture: We engineered a lightweight AI model with MediaPipe and neural networks that uses skeletal coordinates instead of heavy image data.
  • High Accuracy: The system achieved 99.95% accuracy with sub-30ms latency, making it practical for everyday mobile use.
  • Robust Normalization: A custom wrist-scaled normalization method keeps predictions stable across different hand sizes and camera positions.
  • Offline Support: Uses TensorFlow Lite and Android Text-to-Speech for fast, private on-device translation.

How It Works

  1. Start: Open the application on an Android mobile device.
  2. Point Camera: Point the camera at the person signing in Indian Sign Language.
  3. Real-Time Extraction: MediaPipe extracts landmarks from the live video feed.
  4. Inference: The TFLite model predicts the gesture class instantly.
  5. Output: The Text-to-Speech engine speaks the predicted phrase through the device speaker.
